## Design decisions

- **Regenerate-not-recompute-live:** baselines come from the engine (deterministic, seeded); live numbers are **read** from the committed `llm_agent` summary.json (never re-run — the point of the paid cache is we don't pay again, and reading the recorded number is the honest provenance). A `collect_cell(cell, seed)` function returns one merged metrics record per (cell, seed, method).
- **matplotlib is optional (`viz` extra), absent in CI.** Therefore: (a) tests import only the data-assembly functions, never a module that imports matplotlib at top level; (b) `scripts/figures.py` does `import matplotlib` lazily inside render functions; (c) `mypy` already only checks `sim/`, so `figures.py` is exempt, but it must pass `ruff check scripts`.
- **Determinism:** no `Agg`-state leakage between figures (fresh `Figure` per plot, explicit `close`); seeded throughout; a `--check` mode that asserts the committed live numbers match what's read (guards against a silently-moved artifact).
- **Verification is CI-equivalent:** a fresh Python 3.12 venv with `pip install -e ".[dev,data]"` runs `ruff check sim tests scripts` + `pytest` before any commit. The repo `.venv` (3.14, missing pulp) is not trusted for parity.
